# Steno-Web - 100% Client-Side Steganography

Hide and reveal secret messages in images using your browser. **No server, no dependencies, complete privacy!**

## ✨ Features

- 🔒 **100% Client-Side** - Everything runs in your browser
- 🚫 **No Server Required** - Pure HTML/CSS/JavaScript
- 🔐 **Complete Privacy** - Your data never leaves your device

- 📱 **Works Offline** - No internet needed after loading

## 🎯 How to Use

### Encrypt (Hide Message):
1. Click "Encrypt" tab
2. Upload any image (PNG, JPG, JPEG)
3. Type your secret message

### Decrypt (Reveal Message):

## 💡 How It Works

**LSB (Least Significant Bit) Steganography:**
- Your message is converted to binary (1s and 0s)
- Each bit is hidden in the last bit of pixel color values
- The image looks identical to the human eye
- Only PNG preserves the hidden data perfectly

**Technical Details:**
- Uses HTML5 Canvas API to manipulate pixels
- Modifies RGB channels (not alpha)
- Adds delimiter (`###END###`) to mark message end
- Completely client-side - runs in browser's JavaScript engine

## 📝 Important Notes

### Image Format:
- **Encrypt:** Upload PNG, JPG, or JPEG
- **Decrypt:** Must use the PNG file generated by this tool
- **Why PNG?** JPEG compression destroys hidden data

### Message Size:
- Depends on image size
- Larger images = more space
- Example: 1920x1080 image ≈ 700KB of text
- You'll get an error if message is too large

### Browser Compatibility:
- ✅ Chrome (recommended)
- ✅ Firefox
- ✅ Safari
- ✅ Edge
- ✅ Any modern browser with Canvas API support

## 🛠️ Troubleshooting

**"No hidden message found":**
- Make sure you're using a PNG image created by this tool
- JPEGs lose hidden data due to compression
- Don't edit or compress the encrypted image

**"Message too large":**
- Use a larger image
- Or reduce your message size
- Or compress your message before hiding

**Doesn't work when double-clicking:**
- Some browsers block file:// protocol
- Use any simple HTTP server (Python, PHP, Node.js, etc.)
- Or just deploy to Netlify (it's free!)
